# NestCraft

## 🪑 About the Project

**NestCraft** is a modern and responsive furniture website designed to showcase different furniture collections and create a smooth and attractive user experience.

The website was developed as a team project using **HTML, CSS, Bootstrap, JavaScript, and animations**. Each team member worked on a separate section using Git branches, and the sections were later combined into the main website.

## ✨ Features

* Responsive design for different screen sizes
* Modern furniture website layout
* Interactive navigation
* Furniture product sections
* Contact section
* Smooth animations and visual effects
* Bootstrap responsive components
* JavaScript interactions

## 🛠️ Technologies Used

* **HTML5** - Website structure
* **CSS3** - Custom styling and layout
* **Bootstrap 5** - Responsive design and UI components
* **JavaScript** - Interactive functionality
* **CSS Animations** - Visual effects and transitions
* **Git & GitHub** - Version control and teamwork

## 📂 Project Sections

The website was developed using five main branches:

### 1. Home

The Home section introduces the website and displays featured furniture and the main content.

### 2. About

The About section provides information about NestCraft and its purpose.

### 3. Office

The Office section showcases furniture designed for home and office workspaces.

### 4. Kitchen

The Kitchen section presents kitchen furniture and related collections.

### 5. Contact

The Contact section provides ways for visitors to contact NestCraft and includes contact information and location details.

## 🌿 Git Branch Structure

Each major section was developed in a separate branch:

```text
main
│
├── home
├── about
├── office
├── kitchen
└── contact
```

After the individual sections were completed, they were merged into the `main` branch to create the final website.

The project was developed collaboratively. Each team member worked on a specific website section in their own Git branch. Git and GitHub were used to manage the branches, commits, and merging process.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/maryamwahabzada/NestCraft.git
```

2. Open the project folder:

```bash
cd NestCraft
```

3. Open `index.html` in your browser.

Or open the project in **VS Code** and use **Live Server** to run the website.
